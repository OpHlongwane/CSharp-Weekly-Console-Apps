# CSharp-Weekly-Console-Apps
A collection of small C# console applications built for consistent coding practice.

The purpose of this repository is to practise turning requirements into working programs, strengthen C# fundamentals, become more comfortable solving problems independently, and learn Git through regular commits.
Current focus
Starting with the first weekly console application.

Each application will be kept in its own folder. I will add its requirements, implementation notes and learning reflections as I go.
Planned applications
These are starting ideas. The order and scope may change depending on the C# concepts I am learning.
#	Application	Main practice areas
01	Personal Expense Tracker-	Variables, input, conditions, loops, totals
02	Student Marks Manager-	Arrays, lists, methods, validation, calculations
03	Contact Directory- Lists, searching, adding, updating and deleting
04	Banking Simulator- Classes, objects, methods, encapsulation
05	Appointment Manager- OOP, collections, multiple related classes
06	Inventory Tracker- OOP, data organisation, validation and business rules

Each application folder will contain its own C# project and, where useful, a short README explaining:
- What the application does
- Its requirements
- Concepts practised
- How to run it
- What I learned and what I would improve
Weekly workflow
1. Read and understand the requirements.
2. Identify the inputs, outputs and rules.
3. Break the problem into small tasks.
4. Implement the application myself.
5. Run it with normal, boundary and invalid inputs.
6. Review and improve the code.
7. Commit the work to Git with a clear commit message.
   
Git practice
I will practise Git throughout development, not only after an application is finished. The goal is not to produce six perfect applications quickly. The goal is to code regularly, understand the decisions I make, learn from mistakes and gradually become more independent.
